# Panopticon プライバシーポリシー

最終更新日：2026年10月31日

Panopticon（以下「本アプリ」）は、世界のライブ映像を地図に並べ、映像の近くの宿を探せるアプリです。アカウントの登録はなく、利用者を特定する情報を運営者が集めることはありません。

## 1. 本アプリが扱う情報

| 情報 | 使い道 | 保存先・送り先 |
|---|---|---|
| 現在地（許可した場合） | 地図を現在地から表示する | 端末内でのみ使い、外部に送信しません |
| 保存したカメラ | 保存したカメラを一覧で見られるようにする | 端末内のみ |
| 規約に同意したこと | 同意の画面を再び出さないようにする | 端末内のみ |
| 場所の検索語 | 地図で場所を探す | Apple の地図検索に送られます |
| カメラの位置（緯度・経度）、カメラの ID、動画の ID | 近くの宿、配信の状態、配信中の映像を調べる | 運営者の中継サーバーを通じて、楽天ウェブサービスと YouTube に問い合わせます |

宿を探すときに送るのはカメラの位置で、あなたの現在地ではありません。

## 2. 中継サーバー

本アプリは、運営者が Cloudflare Workers で動かしている中継サーバーを通じて、宿と配信の状態を取得します。このとき、1 の情報に加えて、通信に必要な情報（IP アドレスなど）が Cloudflare に届きます。運営者のプログラムは IP アドレスを保存せず、利用者ごとの記録も作りません。問い合わせの結果は、同じ問い合わせを減らすために短い時間だけ一時的に保存します。

Cloudflare による情報の扱いは、[Cloudflare のプライバシーポリシー](https://www.cloudflare.com/privacypolicy/)をご覧ください。

## 3. YouTube

本アプリは YouTube API Services を利用しています。映像は YouTube の埋め込みプレイヤーで再生します。本アプリを利用すると、[YouTube 利用規約](https://www.youtube.com/t/terms)に同意したものとみなされます。

- プレイヤーの内容は YouTube から直接届き、YouTube／Google が Cookie などを使って情報を収集する場合があります。YouTube 上では、広告配信事業者を含む第三者によるコンテンツが配信されることがあります。
- 情報の扱いは [Google プライバシーポリシー](https://policies.google.com/privacy)に従います。
- 本アプリは Google アカウントへのアクセスを求めません。

## 4. 楽天トラベル

宿の情報は楽天ウェブサービスから取得しています。宿の予約リンクにはアフィリエイトが含まれ、予約が成立すると、運営者が紹介料を受け取ることがあります。

- 予約ページはアプリの中のブラウザ（Safari の機能）で開きます。予約・支払いは楽天トラベルのページで行い、入力した情報は楽天グループのポリシーに従って扱われます。
- 紹介の成果を測るため、楽天が Cookie などを使う場合があります。
- あなたの氏名・連絡先・支払いの情報を運営者が受け取ることはありません。

## 5. Apple の地図

地図の表示と場所の検索には Apple の MapKit を使います。検索語などの情報は、Apple のプライバシーポリシーに従って扱われます。

## 6. 広告と解析

本アプリには、広告や利用状況の解析のための SDK は入っていません。アプリをまたいであなたを追跡することもありません。

## 7. 許可の変更とデータの削除

- 位置情報の許可は、「設定」アプリ ＞ プライバシーとセキュリティ ＞ 位置情報サービス ＞ Panopticon からいつでも変更できます。
- 保存したカメラは、カメラのカードからいつでも解除できます。
- 本アプリを削除すると、端末内に保存された情報はすべて削除されます。

## 8. 子どもの利用

本アプリは子ども向けではありません。
