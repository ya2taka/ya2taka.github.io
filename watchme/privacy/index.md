# WatchMe プライバシーポリシー

最終更新日：2026年10月29日

WatchMe（以下「本アプリ」）は、あなたの健康データ・日記・相談を、あなた自身の端末の中で扱うことを基本に設計しています。

## 1. 本アプリが扱う情報

| 情報 | 使い道 | 保存先 |
|---|---|---|
| ヘルスケアのデータ（歩数・心拍・心拍変動・睡眠・アクティブエネルギー・VO2Max・体重・体脂肪率・ワークアウト・睡眠中の皮膚温・呼吸数・血中酸素） | 傾向・体力残量・ストレスなどの目安を計算して表示する、体の値がいつもと違う朝に知らせる、あなたが選んだときに記録を書き出す | 読み取るだけで、本アプリは複製を保存しません（計算結果は端末内） |
| タグ・状態モードの記録、以前の体感の記録 | 計算を自分に合わせる、タグと翌朝の傾向を比べる | 端末内のみ |
| 習慣（名前・週に何日やるか・自動でチェックする条件・やった日の記録） | 続き具合を表示する、ヘルスケアの記録や日記から自動でチェックする、習慣をやった日と翌朝の体・その日の日記の気分を比べる | 端末内のみ |
| 日記（チャットで話した内容と日記の文章、気分、話から推定した体の調子） | 日記として表示する、体の調子で体力残量の計算を自分に合わせる | 端末内のみ |
| 相談（チャットで話した内容と、会話から推定した今の気持ちと体の調子） | 相談の記録として表示する、体の調子で体力残量の計算を自分に合わせる | 端末内のみ |
| 性格の質問（Mini-IPIP）への回答 | 性格の傾向を表示する | 端末内のみ |
| GHOST.md（日記と相談の内容から書き留めた、あなたについての短い記述と、あなたが書いた項目） | 表示する、日記と相談の聞き手に一部を伝える、あなたが選んだときに書き出す | 端末内のみ |
| 日記・相談で話した声 | 端末内で文字にする | 保存しません |
| 通知・表示などの設定 | アプリの設定 | 端末内のみ |

本アプリにはサーバーがなく、上の情報を本アプリの運営者が受け取ることはありません。iCloud にも保存しません。

## 2. ヘルスケア（HealthKit）

- 読み取りは、あなたが許可した項目だけです。許可は「設定」アプリ ＞ ヘルスケア ＞ データアクセスとデバイス ＞ WatchMe からいつでも変更できます。
- 書き込むのは、あなたが入力した体重・体脂肪率、日記で選んだ気分、相談を終えたときに会話から推定した今の気持ち（いずれも心の状態）だけです。相談の会話の文章はヘルスケアに書き込みません。
- ヘルスケアのデータを、広告やマーケティングに使ったり、第三者（広告事業者を含む）に渡したりすることはありません。

## 3. Apple Intelligence（端末内の AI）

日記の質問と文章、相談の返答と今の気持ちの推定、GHOST.md の項目は、対応する端末では Apple の端末内の言語モデルで作ります。日記・相談・GHOST.md の内容が端末の外に送られることはありません（あなたが書き出したとき（6 を参照）と、次の「自分の API キーを使う場合」を除きます）。GHOST.md では、会話から性格を推定しません。相談の聞き手は AI で、医療の専門家ではありません。

### 自分の API キーを使う場合（AI の接続）

設定の「AI の接続」で、AI サービス（Claude（Anthropic）・OpenAI・Gemini（Google）、またはあなたが入力した OpenAI 互換の接続先）を選び、送る内容に同意して、あなた自身の API キーを保存した場合に限り、日記の聞き手の質問と日記の文章、相談の返答と今の気持ちの推定を、そのサービスで作ります。この設定は、初めはオフです。

- 送るもの：日記の聞き手との対話、相談での発言（返答には直近 12 件、気持ちの推定とやった習慣の読み取りには直近 24 件まで）、GHOST.md のうち聞き手に伝える項目（GHOST.md の設定でオンのとき）、習慣の名前（ヘルスケアや日記で自動でチェックしない習慣。日記で習慣について聞くときと、話からやった習慣を読み取るとき）。
- 送らないもの：ヘルスケアのデータ、体感・タグ・状態モード、習慣をやった日の記録、性格の質問への回答、声の録音。
- 送り先は、あなたが選んだサービスだけです。本アプリの運営者のサーバーは経由せず、運営者がその内容を受け取ることはありません。送った内容は、そのサービスの規約とプライバシーポリシーに従って扱われます。利用料は、あなたのそのサービスのアカウントに請求されます。
- 接続を確かめるときとモデルの一覧を読み込むときは、日記や相談の内容は送りません。
- API キーは端末のキーチェーンにだけ保存し、iCloud キーチェーンには同期しません。キーは選んだサービスへの送信にだけ使います。
- 設定はいつでも「使わない」に戻せます。すでに送った内容の削除は、そのサービスで行ってください。

## 4. あなたの端末どうしの送信

- Apple Watch には、計算した値（体力残量など）を、ペアリングした Apple Watch へ直接送ります。
- Apple Watch のアプリは、iPhone から値が届くまでのあいだも体力残量と歩数を更新するため、Apple Watch で記録した心拍・アクティブエネルギー・睡眠・歩数を読み取り、Apple Watch の中で計算します。書き込みはしません。
- iPad では、Apple のヘルスケアの iCloud 同期を通じて iPhone のデータを読み取ります（同期の設定はあなたが行います）。

## 5. 広告

本アプリは Google LLC の広告サービス（Google AdMob）を使って広告を表示します。

- 広告のために、Google は端末の識別子、IP アドレス、広告の表示・タップなどの情報を収集する場合があります。詳しくは Google のポリシー（https://policies.google.com/technologies/partner-sites）をご覧ください。
- トラッキングを許可するかどうかは、初めて広告を表示するときにお尋ねします。許可しない場合は、あなたに合わせない広告を表示します。
- 英国・スイスなど、法律で同意が求められる地域では、広告を表示する前に Google の同意の画面（User Messaging Platform）で、広告のためのデータの利用に同意するかをお尋ねします。同意しない場合は、データの利用を限った広告を表示します。答えるまでは広告を表示しません。答えは設定の「広告のプライバシー設定」からいつでも変えられます。
- 健康データ・日記・相談・性格の質問への回答・GHOST.md・体感などを、広告のリクエストに含めたり、広告のターゲティングに使ったりすることはありません。

## 6. 共有

日記を「ほかのアプリに送る」を選んだときだけ、あなたが選んだアプリに日記の文章を渡します。

GHOST.md は、「書き出す」でコピーまたは共有を選んだときだけ、あなたが選んだ見出しの文章を、あなたが選んだアプリに渡します。ほかの AI のサービスに貼り付けると、その内容はそのサービスに送られ、そのサービスのプライバシーポリシーに従って扱われます。本アプリが自動で送ることはありません。

設定の「記録を書き出す」では、あなたが期間を選んで「メールで送る」または「ほかの方法で共有・印刷」を選んだときだけ、その期間の記録を PDF と CSV にして、あなたが選んだ相手やアプリに渡します（受診のときに医師に見せる、などのため）。

- 含めるもの：ヘルスケアのデータの日ごとの値（安静時心拍・心拍変動・睡眠・歩数・VO2Max・体重・体脂肪率・睡眠中の皮膚温・呼吸数・血中酸素）、体力残量とストレスの目安、体調不良・旅行中の期間、タグ、日記の気分（5 段階）。
- 含めないもの：日記の本文、相談、GHOST.md、性格の質問への回答、習慣の記録、声。
- メールは iOS のメールの作成画面で開き、宛先と内容をあなたが確かめてから、あなた自身のメールで送ります。入力した宛先は保存しません。本アプリの運営者のサーバーは経由せず、運営者がその内容を受け取ることはありません。
- 渡したファイルは、受け取った相手の端末やメールのサービスに残ります。本アプリが自動で送ることはありません。

## 7. データの削除

- 日記は、アプリ内の日記の画面から削除できます。
- 相談は、個性タブの「相談の記録」から削除できます。
- 習慣は、習慣化タブの各習慣の画面から削除できます。やった日の記録も一緒に削除されます。
- 性格の質問への回答は、個性タブの性格の画面から削除できます。
- GHOST.md は、個性タブの GHOST.md の画面から、項目ごとまたはすべて削除できます。書き出したあとの文章は、渡した先のアプリやサービスで削除してください。
- 「記録を書き出す」で作ったファイルは、作り直すたびに端末内の一時的な場所から消します。渡したあとのファイルは、渡した先で削除してください。
- 自分の API キーは、設定の「AI の接続」から削除できます。
- 本アプリを削除すると、端末内に保存された記録はすべて削除されます。
- ヘルスケアに書き込んだ体重・体脂肪率・気分・気持ちは、ヘルスケアアプリから削除できます。

## 8. 子どもの利用

本アプリは子ども向けではありません。
